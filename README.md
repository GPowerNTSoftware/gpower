# G*Power 3.1.9.7 for Windows

<p align="center"><img src="gpower-logo.svg" alt="G*Power statistical power analysis" width="440"></p>

G*Power is statistical power-analysis software for planning and evaluating research studies. Version 3.1.9.7 for Windows supports power analyses for many *t* tests, *F* tests, chi-square tests, *z* tests, and some exact tests. It also calculates effect sizes and displays results in tables and graphs.

## What you can do

- **Plan sample size:** estimate the number of participants needed for a chosen statistical test, effect size, significance level, and target power.
- **Evaluate power:** explore the power associated with a study's sample size and statistical assumptions.
- **Calculate effect sizes:** derive or inspect effect sizes for supported tests.
- **Visualize results:** review calculations in tables and graphical power plots.

G*Power is used in biomedical, behavioral, and social-science research. The available procedures depend on the selected test and analysis.
