Statistical power analysis software

G*Power 3.1.9.7 for Windows

G*Power calculates statistical power for t tests, F tests, chi-square tests, z tests, and some exact tests. It can also calculate effect sizes and display results graphically.

The G*Power 3.1.9.7 Windows ZIP includes GPowerNT.exe. Extract the archive before running the program.
