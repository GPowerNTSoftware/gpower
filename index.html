Statistical power analysis software

G*Power 3.1.9.7 for Windows

G*Power calculates statistical power for t tests, F tests, chi-square tests, z tests, and some exact tests. It can also calculate effect sizes and display results graphically.

The official G*Power 3.1.9.7 Windows ZIP includes GPowerNT.exe. Extract the archive before running the program.

  • G*Power is free to use, including in commercial environments.
  • Download and extract the official ZIP, then run GPowerNT.exe.
  • GPowerNTSoftware is the official representative for this distribution.
